# 美股六大策略戰情板 · 手機 App

`USstocks_Sixways_dashboard.html` 的手機版，單檔網頁應用，可安裝到主畫面（PWA）。
與桌機版同一份 `us_daily.json`、同一套判定 —— 分析一行都沒有在手機端重算。

## 內容
| 分頁 | 區塊 |
|---|---|
| 大盤 | 綜合方向票數、VIX、四指數明細（點進去看轉折高低與壓力支撐）、規則式解讀 |
| 觀察 | 十檔核心關注股的現況與六面向檢核（點進去看逐面向判定） |
| 全池 | 539 檔個股／ETF 的訊號，含確認進場徽章與週線底部反轉徽章，可篩選排序 |

**不含「持股趨勢研判」**（指定排除）。連帶把 `hold_list` 與每一列的 `hold` 旗標都剝掉 ——
這份託管在公開的 GitHub Pages，那是唯一會透露個人持倉的欄位。

## 安裝到手機
用手機瀏覽器開啟網址：
- **iPhone**：Safari → 分享 → 加入主畫面
- **Android**：Chrome → ⋮ → 安裝應用程式

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 應用程式本體（含當日資料，約 187 KB） |
| `d/<代號>.json` | 逐項判定長文（六面向、進出場檢核、週線），點進詳情才抓 |
| `manifest.json` | PWA 設定 |
| `sw.js` | Service Worker（頁面網路優先、詳情快取優先） |
| `icons/` | 應用程式圖示 |

## 每天怎麼更新
`us_app.py` 由 `run_us_daily.sh` 在每日流程最後呼叫，重產整個 `app/`。
把 `app/` 的內容推上 GitHub Pages 才會反映到手機上。

## 注意
本工具僅陳述規則判定結果與風險，不構成投資建議。所有數字來自歷史資料與規則運算。
